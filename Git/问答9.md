# 问答 9：裸仓库与普通仓库

## 提问

什么是裸仓库？它与普通仓库有什么区别？为什么可以在 Windows 电脑 A 上使用裸仓库作为远端，让电脑 B 推送和获取提交？

## 回答

普通仓库包含 Git 的版本数据和可编辑的项目文件（工作区），适合日常开发。开发者可以在其中修改文件，再运行 `git add` 和 `git commit`。

裸仓库保存 Git 的版本数据、提交历史、分支和标签，但没有检出的项目文件和工作区。它通常以 `.git` 结尾，例如 `ProjectA.git`，常用于通过 `git push` 和 `git fetch` 与其他仓库交换提交历史。Git 官方文档将裸仓库描述为通常用于与他人交换提交历史的仓库。[Git 仓库目录结构文档](https://git-scm.com/docs/gitrepository-layout)

在电脑 A 上，可以使用以下命令创建裸仓库：

```powershell
git init --bare D:\GitRepos\ProjectA.git
```

电脑 B 保留普通仓库用于编辑和提交代码，再把电脑 A 上的裸仓库配置为远端。之后，电脑 B 可以向它推送提交，也可以从它获取提交。裸仓库没有工作区，因此不能像普通仓库那样直接编辑项目文件或运行 `git add`。Git 配置文档说明，没有工作区的仓库会禁用一些需要工作区的操作。[Git 配置文档](https://git-scm.com/docs/git-config)

```text
电脑 B：普通仓库
编辑代码、git add、git commit
        │
        │ git push / git fetch
        ▼
电脑 A：裸仓库 ProjectA.git
保存提交历史，作为共享远端
```

## 补充问答：裸仓库与远端仓库的关系

### 提问

裸仓库是不是就相当于远端仓库？

### 回答

在实际使用中，裸仓库经常被用作远端仓库，因此电脑 A 上的 `ProjectA.git` 可以既是裸仓库，也是电脑 B 所连接的远端仓库。

### 注释

“裸仓库”描述仓库的结构，表示它没有工作区和检出的项目文件；“远端仓库”描述它相对于另一份仓库所扮演的角色。两个概念不同，但常常指向同一个仓库。例如，电脑 A 上的仓库是裸仓库，而电脑 B 把它配置为远端仓库。
