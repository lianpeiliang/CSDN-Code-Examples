# 问答 1：Git fetch

## 提问

讲讲 `git fetch`。

## 回答

`git fetch` 会从远程仓库下载新的提交和相关对象，并更新本地记录的远程分支位置，例如 `origin/main`。它不会把这些提交合并到当前分支，也不会修改工作区中的文件。

例如，远程 `main` 分支比本地多了一个提交时，执行 `git fetch origin` 后，本地的 `origin/main` 会更新到新提交，而本地 `main` 仍停留在原来的位置。此时可以先查看远程新增的提交，再决定是否通过 `merge` 或 `rebase` 整合。

```bash
git fetch origin
git log --oneline main..origin/main
```

## 思考

`git fetch` 可以先将远程仓库的变化获取到本地，但不会自动合并这些变化。获取完成后，可以在本地查看远程有哪些更新，再决定如何处理。

## 回复

对，理解正确。`git fetch` 会把远端的新提交和相关对象下载到本地，并更新 `origin/main` 这样的远程分支记录；当前分支和工作区保持原样。之后可以比较本地分支与远程分支记录，查看新增提交，再决定是否通过 `merge` 或 `rebase` 将更新整合进当前分支。
